# WASHFLOW — комплект для Claude Code

Внутри: единый промпт `CLAUDE_CODE_PROMPT.md`, общий дизайн-референс и 6 отдельных экранов в `screenshots/`.

## Как запустить
1. Распакуй содержимое архива в отдельную папку `WASHFLOW`.
2. Открой эту папку в Claude Code (папка должна быть рабочей директорией).
3. Вставь в чат Claude Code: `Прочитай CLAUDE_CODE_PROMPT.md и изучи все изображения в screenshots/. Выполни задачу целиком.`
4. Когда Claude Code попросит разрешение на необходимые локальные операции или подключение внешних сервисов, проверь запрос и подтверди нужные действия.

## Экраны
- `00_overview_all_screens.png` — общий дизайн-референс
- `01_home.png` — Главная
- `02_wash_scenario.png` — Сценарий мойки
- `03_my_equipment.png` — Моё оборудование
- `04_my_chemistry.png` — Моя химия
- `05_chemistry_catalog.png` — Каталог автохимии
- `06_step_by_step.png` — Пошаговая мойка

Обрати внимание: изображённые упаковки, время, остатки и дозировки в концептуальных макетах не проверены по первоисточникам. Подпись «Макет для Валентина Андреевича» — только на макетах, в самом приложении не нужна.
